# Customer Relationship Management System

A web-based Customer Relationship Management (CRM) system developed using PHP and MySQL. The application provides a centralized platform to manage customer information, user accounts, support tickets, and other customer-related activities.

## 🚀 Features

- User Registration and Login
- User Authentication
- Customer Profile Management
- Dashboard
- Create and Manage Support Tickets
- View Tickets
- Get Quote functionality
- Change Password
- Forgot Password functionality
- User Profile Management
- Admin Panel
- Database-driven customer management

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** Apache
- **Development Environment:** XAMPP
- **Database Management:** phpMyAdmin
- **Libraries:** jQuery
